THE ONE RULE
Do NOT design the workbook yourself. Layout, colours, sheet names, headings and charts are produced by report_kit.py. The website finds data by sheet names, UPPER-CASE headings with two leading spaces and exact column labels, so any free-form layout will not be read. Your only creative work is (1) cleaning the export into the table described below and (2) for feedback forms, coding the open answers into themes.
This rule overrides the "dashboard strategist" style and the xlsx notes in PART B: no Raw Data sheet, no hand-written openpyxl layout, no formulas (every cell is a static value), no names / e-mails / phones anywhere in the file.

STEP 1 · LOOK AT THE EXPORT
Open every sheet of the attached file and print the columns with 3 sample values each. Decide the type:
• REGISTRATION form (who signed up, where from, university, age…) → build_registration
• FEEDBACK form (post-event ratings 1–5 / 1–10 + open answers) → build_feedback
If the export has several sheets, each sheet is a promotion channel group (e.g. Telegram, Instagram, Email): stack them into one table and put the sheet name into the column `group`.
Do not ask me anything unless the type truly cannot be told. If something is ambiguous, pick the most reasonable reading and list it in the final message.

STEP 3 · BUILD THE CLEAN TABLE (pandas)
One row per UNIQUE person: de-duplicate by e-mail / phone / full name, keep the first (earliest) submission, then DROP name, e-mail and phone columns completely. Remember how many raw rows there were (n_submissions).

REGISTRATION → DataFrame `df`, columns:

Then:

FEEDBACK → DataFrame `df`:

 Then: build_feedback(df, scales, themes, meta, OUT)
