## Проекты в репозитории

### `utm-tracker/`: трекер ссылок и аналитики AIESEC KZ

- **Стек:** Next.js 15, Prisma, Neon Postgres, деплой на Vercel.
- **Домен:** `https://aieseckz.vercel.app`. Старый `ewapewa-utm-tracker.vercel.app` нужно оставить в Vercel → Domains, чтобы работали старые ссылки.
- **Проверки:** `npx tsc --noEmit`, `npx vitest run` (DB-тестам нужен `TEST_DATABASE_URL` к локальному Postgres; сейчас 145 тестов), `npx next build`. CI в `.github/workflows/ci.yml` прогоняет tsc, тесты и build.
- **Миграции:** `prisma/migrations/0001…0009`, на проде применяются при деплое (`scripts/migrate-production.mjs`).

Что сделано (PR #20–#32, все смерджены):

**Ссылки и лиды**
- Короткие ссылки `/r/<slug>`, клики, лиды.
- Строка `/t.js` в настройках сайта Тильды делает три вещи:
  - подставляет `click_id` и UTM в формы;
  - отправляет лид;
  - собирает аналитику **всех** форм.
- Прямые регистрации без ссылки трекера тоже считаются: кампания определяется по адресу страницы.

**Папки проектов** (`src/lib/projectGroups.ts`)
- Кампании группируются по названию: основная, EwA2oGX, EwA2MXP.
- Внутри папки: ручные цифры и 4 показателя:
  - oGX regs / project regs;
  - oGX / show-up;
  - AIESEC.org signups / regs;
  - signups / show-up.
- **Код:** `projectStats.ts`, `projectNumbers.ts`, `ProjectNumbers.tsx`.

**Роли**
- Роли: admin / manager / viewer; самостоятельная регистрация с одобрением админа.
- PM редактирует только свои папки проектов.
- **Код:** `src/lib/permissions.ts`, `auth.ts`.

**Аналитика форм** (раздел Forms)
- Коллектор `POST /api/collect` принимает данные только с сайтов, на которые ведут ссылки трекера. Хранится только хеш IP, введённый текст не сохраняется.
- Отчёты: воронка, таблица по вопросам, места ухода, причины блокировки, срезы, CSV.
- Форма сама попадает в проект по ссылкам страницы или UTM; проект можно сменить вручную.
- **Код:** `src/lib/formAnalytics/*`, `src/lib/snippetForms.ts`.
- **Проверка в браузере:** `npm run check:forms`.

**Отчёты (Reports)**
- Загрузка аналитики в Excel (Feedback / Registration), в том числе массовая.
- Понимает и **старый шаблон 2025 года**: заголовки выделены жирным, листы «Daily Trend» и «Segment Analysis».
- **Код:** `src/lib/reports/*`.

**Projects / Compare**
- Метрики проекта считаются из отчётов (`src/lib/projects/metrics.ts`, `METRICS_VERSION=2`), есть запасные варианты для старого шаблона.

**Отметки NEW**
