## Как работать

- Отвечать **на русском**. Пользователь не программист: объяснять по шагам, где нажать в Vercel или Тильде и что вставить.
- **Рабочая ветка:** `claude/determined-carson-ghy43b`. **Прод (Vercel):** `claude/brick-toy-promo-video-w4leay`.
- **Как выкатывать.** PR не обязателен:
  1. запушить рабочую ветку;
  2. дождаться зелёного CI;
  3. перемотать прод fast-forward: `git push origin <коммит>:refs/heads/claude/brick-toy-promo-video-w4leay`.

  Это постоянное разрешение владельца. `git push -f` не использовать. Если прод ушёл вперёд, сначала влить его в рабочую ветку.
- **GitHub CLI** (`gh`) в этой среде не установлен. Push работает через Git Credential Manager. Для репозитория закреплён аккаунт `bekshgh`: `git config credential.https://github.com.username bekshgh`. Чтобы окно входа не висело, пушить с `GCM_INTERACTIVE=never GIT_TERMINAL_PROMPT=0`.
- **Статус CI** без входа: `https://api.github.com/repos/bekshgh/ewapewa/commits/<sha>/check-runs`. Логи и перезапуск только с токеном `bekshgh` (`git credential fill`).
- **Секреты:** `.env` не читать, к продовой базе доступа нет.

## `utm-tracker/`: трекер ссылок и аналитики AIESEC KZ

- **Стек:** Next.js 15, Prisma, Neon Postgres, Vercel. Шрифты лежат в `src/app/fonts`; кириллицу рисует Onest.
- **Домены:** основной `https://aieseckz.vercel.app`, дополнительные `zimran-aiesec.vercel.app` и `businesscup-aiesec.vercel.app`. Старый `ewapewa-utm-tracker.vercel.app` не удалять: старые ссылки.
- **Проверки:**
  - `npx tsc --noEmit`;
  - `npx vitest run --no-file-parallelism`, с `TEST_DATABASE_URL` к Postgres (190+ тестов);
  - `npx next build`.

  Локально Postgres поднимается через `embedded-postgres` во временной папке, `initdbFlags: ["--encoding=UTF8", "--locale=C"]`. CI (`.github/workflows/ci.yml`, ubuntu-24.04) сам поднимает Postgres и прогоняет и DB-тесты.
- **Миграции** `prisma/migrations/0001…0014` применяются на проде при деплое (`scripts/migrate-production.mjs`).
- **Время** везде по Алматы (`TIME_ZONE` / `localDay` в `src/lib/utils.ts`). В SQL колонки дат хранят UTC без пояса: сравнивать как `AT TIME ZONE 'UTC'`.

### Ссылки и клики
- `/r/<slug>` (`src/app/r/[slug]/route.ts`).
- **Боты** (`src/lib/bots.ts`). Превью мессенджеров и краулеры не считаются. Скрипты отсекаются только на онлайн-ссылках; на офлайн/QR сканеры засчитываются.
- **Повторы:** то же устройство в течение 30 секунд — один клик.
- **Пауза.** Приостановленная или архивная ссылка, или приостановленная кампания: ссылка ведёт на страницу, но клик не пишется. Неизвестный адрес — 404.
- **Уникальный клик** = отдельное устройство (IP-хеш + браузер) за период, считается при запросе (`uniqueClicksByLink`).
- **Домены ссылок:** `TrackingLink.shortDomain`, список в Settings → Short link domains. Выбор домена есть в конструкторе, в Create link и в Edit.
- **QR** рисуется в браузере (библиотека `qrcode`): PNG 1024 и SVG.
- **Редактирование** ссылки: кнопка Edit на Links и на странице кампании. Адрес `/r/` не меняется.

### Лиды
- Скрипт `/t.js` (`src/lib/snippet.ts` и `snippetForms.ts`) подставляет `click_id` и UTM, записывает лид и собирает аналитику форм. Метки в cookie обновляются разом при новом переходе.
- **Когда записывается лид.** Только после успешной отправки:
  - Тильда — по success-callback, событию `tildaform:aftersuccess` или по её сообщению «спасибо»;
  - React-формы — по экрану «Спасибо», `window.tlFormSuccess()` или событию `trackline:success`.
- **Метки лида.** Если лид пришёл по ссылке трекера, берутся метки ссылки (`preferLinkTags`). В отчётах такой лид считается по меткам ссылки.
- **Прямые регистрации** без ссылки определяются по адресу страницы, `utm_source=direct`.
- **Страница Leads:** поиск, вкладки кампаний, по 100 на страницу. Контакты видят все одобренные пользователи; пользователь решил это пока не менять.

### Кампании и проекты
- **Названия** только «Название F'26 / S'26» (`src/lib/naming.ts`). Старые названия исправляются в Settings → Old names.
- **Проект и кампания.** При создании проекта создаётся кампания с тем же названием (кроме проектов из массовой загрузки отчётов).
- **Кампания:**
  - конструктор UTM-ссылок, список ссылок, Edit (название, тип, описание);
  - Pause и Resume; статусы `active` / `paused` / `archived`;
  - удаление одной транзакцией.
- **Папки проектов** (`src/lib/projectGroups.ts`): основная кампания плюс EwA2oGX / EwA2MXP, ручные цифры. Из папки есть ссылка на карточку проекта в Projects.
- **Projects** (`src/lib/projects/*`): метрики считаются из отчётов.

### Аналитика форм (Forms)
- **Коллектор** `POST /api/collect` принимает данные только с доменов, на которые ведут ссылки трекера.
- **Многошаговые React-формы** поддерживаются, например Business Cup на `businesscup.zimran.io/en/apply`. Список вопросов для не-тильдовских форм только дополняется (`ctx.steps`). Форма записывается под адресом страницы, на которой стоит.
- **Название формы** можно переименовать (`customTitle`).

### Отчёты (Reports)
- Загрузка Excel (Feedback / Registration), массовая. Понимает старый шаблон 2025 года.
- Страница `/reports/guide` и `report_kit.py` помогают готовить файлы в едином формате.

### Интерфейс
- Боковая панель: Webhook, Guideline, Data и Settings собраны в Others. У Team — число заявок на вход. Страницы кампаний обновляются без перезагрузки (`LiveRefresh`).
- Отметки NEW сами пропадут 15.11.2026.
- Язык: русский по умолчанию, переключатель RU / EN внизу боковой панели и на входе (cookie `lang`). В коде пишется английский текст `t("…")` (`getT()` на сервере, `useT()` в клиенте), русский лежит в `src/lib/i18n/ru/*.ts`. `tests/i18n.test.ts` падает, если у `t("…")` нет перевода. Гайд — две статьи: `guide/en.tsx` и `guide/ru.tsx`. Содержимое отчётов (из Excel) и сообщения API не переводятся.
